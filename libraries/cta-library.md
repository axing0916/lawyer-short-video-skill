# CTA 库

CTA 提供下一步，不承诺结果。每个领域给 8 个可调整骨架。

## 民间借贷

1. 保存这份证据清单，再按时间顺序整理材料。
2. 先核对款项交付和借贷合意是否都有记录。
3. 把还款约定与后续催收记录分开归档。
4. 如果关键日期不清楚，先做时间线再判断下一步。
5. 不确定利息口径时，按现行规则核验后再计算。
6. 有担保安排的，单独核对主体、范围和期间。
7. 证据冲突时先保留原始载体，不要只存截图。
8. 个案金额和阶段不同，必要时带着材料寻求专业核验。

## 合同纠纷

1. 把合同文本、变更记录和实际履行材料放在一起核对。
2. 先确认谁签、谁履行、谁收款，不要只看抬头。
3. 通知或解除前，先检查合同约定和送达证据。
4. 损失主张要从发生、金额和因果关系分别准备材料。
5. 有验收争议的，先固定交付内容和时间。
6. 不要覆盖原始聊天、邮件和文件版本。
7. 争议解决条款可能影响程序，提交前先核验。
8. 情况复杂时，用完整材料获得针对性的法律意见。

## 公司法

1. 先找章程、决议、出资和登记材料，不凭口头身份判断。
2. 区分公司、股东和管理人员各自的行为与责任。
3. 重大决定先核对权限和程序，不只看签名或盖章。
4. 关联交易要保存定价、审批和实际履行依据。
5. 股权变化先做时间线，再核对每一步文件。
6. 公司债务问题不要直接跳到个人责任结论。
7. 规则时点可能影响判断，按行为发生时的制度核验。
8. 需要采取动作前，让专业人士先看完整公司文件。

## 婚姻家事

1. 先区分财产取得时间、来源和登记，再讨论归属。
2. 涉及债务时，保存用途和共同意思的相关材料。
3. 有子女安排的，把稳定照护和现实可执行性放在前面。
4. 协议内容要具体到对象、金额、时间和履行方式。
5. 涉及人身安全时，优先寻求安全支持和专业帮助。
6. 不要在公开评论区披露未成年人或家庭隐私。
7. 情绪高峰期先保留材料，避免不可逆处置。
8. 个案事实差异大，需要时进行私密、合规的专业咨询。
