# 高风险表达替换

| 高风险 | 建议替换 |
|---|---|
| 保证胜诉 | 结合完整事实和证据评估可行性 |
| 一定能追回 | 还要考虑证据、程序和实际执行条件 |
| 99%的人不知道 | 很多人容易忽略其中一个条件 |
| 法官不会告诉你 | 公开规则中容易被忽略的一点 |
| 行业内幕 | 从公开规则和材料能看到的判断路径 |
| 马上私信，否则来不及 | 如涉及期间或紧急风险，请尽快核验具体时间点 |
| 我办过一个一模一样的案子 | 以下为虚构教学情景 / 输入已授权的脱敏案例 |
| 有转账就能赢 | 转账只是材料之一，还要核对关系和其他证据 |
| 签了字就绝对有效 | 效力仍取决于主体、意思表示、内容和适用规则 |
