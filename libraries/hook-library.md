# Hook 库

Hook 是价值承诺，不是夸张工具。以下六种模式每种提供 3 个骨架，方括号必须由已核验输入填充。

## 1. 场景识别

适用：受众能快速判断“与我有关”。

- “如果你现在正处在【具体阶段】，先别急着【常见动作】。”
- “【角色】遇到【事件】时，第一步往往不是【直觉动作】。”
- “收到【文件/通知】后，先看这三个位置。”

预期：提高相关性；风险：场景过宽。

## 2. 误区纠正

- “很多人把【A】当成【B】，但真正要先确认的是【条件】。”
- “有【单一材料】不等于【绝对结论】。”
- “问题不只在【表面争议】，还在【证据/程序节点】。”

预期：引发讨论；风险：为反常识删条件。

## 3. 风险前置

- “这件事最贵的，可能不是【表面成本】，而是错过【节点】。”
- “在【动作】之前，先保留【材料类别】。”
- “如果【条件】还没确认，先不要做【不可逆动作】。”

预期：促进收藏；风险：恐吓。

## 4. 决策对比

- “同样是【现象】，有【证据A】和只有【证据B】，处理顺序不同。”
- “【选择A】和【选择B】的差别，在于谁承担【风险】。”
- “不是越快【动作】越好，先看你处在哪个阶段。”

预期：展示专业判断；风险：比较口径不一。

## 5. 清单承诺

- “给你一份【情境】下的三步检查表。”
- “遇到【问题】，先把这四类材料放到一起。”
- “一分钟核对：你现在缺的是事实、证据，还是程序动作。”

预期：收藏；风险：把清单绝对化。

## 6. 开放问题

- “为什么同样的【行为】，结果会因为【条件】不同而变化？”
- “如果只能保留一份材料，你会先选哪一份？”
- “这类争议，真正决定下一步的是什么？”

预期：探索与评论；风险：正文不兑现。

## 选择指南

依据主目标选一个模式。Hook 中的事实必须有来源；“内幕”“保证”“99%”不属于可用模式。发布后用真实留存数据评估，不预填效果。
