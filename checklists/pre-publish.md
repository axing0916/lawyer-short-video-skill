# 发布前检查

## 事实与法律

- [ ] 每个关键事实可回指来源
- [ ] 单方主张未写成已证实事实
- [ ] 法律规则已核验效力、时点、地区和条件
- [ ] 主体、请求、证据、金额、日期和期间一致

## 隐私与执业

- [ ] 已取得必要授权并完成二次重识别检查
- [ ] 无客户、未成年人、证人或商业秘密泄露
- [ ] 无胜诉、追回、流量或转化保证
- [ ] 无虚构经历、履历、数据和所谓内幕

## 表达与交付

- [ ] Hook 与正文兑现
- [ ] 实际朗读时长合格
- [ ] CTA 中性且不误导
- [ ] 所有 `【待补充】`、`【需核实】` 已解决或明确阻断
- [ ] 已记录审核人、版本和状态
