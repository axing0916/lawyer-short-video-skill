# 生成示例：对比冲击

> 虚构教学情景。

## 输入

合同成果交付后，一种情况有明确验收回复，另一种只有长期沉默。目标：探索；时长：60 秒。

## 处理

同口径对比“有明确确认”和“仅沉默”，不预设沉默的法律效果。

## 最终输出

口播：“同样是交付完成，有一封明确的验收回复，和只有‘对方一直没说话’，证据强度并不一样。前者至少能看到对方的明确态度；后者还要继续核对合同里的验收条款、交付是否到达、对方有没有实际使用，以及是否提出过异议。所以，别只保存成果文件，交付、送达、回复和使用记录要成套保存。沉默产生什么效果，需要结合具体约定和现行规则核验。”

状态：`需法律核验`。
