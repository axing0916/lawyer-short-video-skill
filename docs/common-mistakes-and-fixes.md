# 常见错误与改正示例

以下 8 个案例均为脱敏后的示例材料，仅用于说明常见错误模式，不对应任何真实当事人或案件。使用前请先自行脱敏客户材料，不要粘贴未脱敏原始案卷。

## 1. 编造细节

**问题**：材料中缺失的对话、心理活动、动作被脑补，让读者误以为是已核实事实。

❌ 错误示例：
```
当事人在法庭上情绪崩溃，痛哭流涕地对法官说："我真的没有骗她！"
```

✅ 正确做法：
```
材料未记录当事人在庭审现场的具体反应。已确认事实仅为：一审判决认定其
承担 30% 责任。`【待补充：庭审现场情况】`
```

## 2. 虚假保证

**问题**：把可能结果写成确定承诺，或暗示"关注/咨询"能带来特定胜诉结果。

❌ 错误示例：
```
按照这个方法操作，你的案子100%能赢！关注我，包你胜诉。
```

✅ 正确做法：
```
以上步骤有助于保全证据，但案件结果取决于具体事实、证据和法官裁量，
不能保证结果。如需个案判断，建议咨询律师。
```

## 3. 虚构未标记

**问题**：为了教学效果编造情景，但未按规范标注"虚构教学情景"，让观众误以为真实发生。

❌ 错误示例：
```
上周我遇到一个客户，借给朋友10万元没打借条，结果……
```
（实际为教学编写的情景，未做任何标注）

✅ 正确做法：
```
【虚构教学情景】以下情景为便于说明法律要点而虚构，不对应任何真实
当事人或案件。

情景：甲借给乙10万元未打借条……
```

## 4. 术语混用

**问题**：混淆材料事实、当事人主张、法律判断和表达建议，让观众无法分辨哪些是已核实内容。

❌ 错误示例：
```
他借钱不还，法院肯定支持我全额要回本金和利息。
```

✅ 正确做法：
```
- 当事人主张：对方借款后未偿还。
- 材料事实：仅有转账记录，无借条。
- 法律判断：`【需核实：无书面借条时能否认定借贷关系及利息计算】`
```

## 5. 地域/时效错误

**问题**：忽略法律的地域适用范围和生效时点，把某地或某时期的规则当作普遍现行规则。

❌ 错误示例：
```
根据法律规定，借款年利率超过36%的部分不受法律保护。
```
（未说明该表述对应的时间版本和地区，也未核实是否为现行有效规定）

✅ 正确做法：
```
在【全国/需核实具体地区】，截至【需核实：行为发生时点对应的现行
版本】，民间借贷利率保护上限按照相关司法解释执行，具体数值和适用
条件请核验现行文本后再发布。`【需核实】`
```

## 6. 隐私泄露

**问题**：未脱敏即使用真实姓名、身份证号、手机号、案号等可识别信息。

❌ 错误示例：
```
当事人张某某（身份证：110105-XXXX-XXX-XXXX）诉李某某民间借贷纠纷
一案（(2024)京0105民初XXXXX号）……
```

✅ 正确做法：
```
当事人甲诉乙民间借贷纠纷一案（案号已脱敏）。发布前已确认：姓名、
证件号、手机号、案号等可识别信息均已替换或删除。
```

## 7. CTA 不匹配

**问题**：结尾行动号召（CTA）与前文传播目标不一致，例如内容走"收藏"结构却在结尾要求转发，或走"专业信任"结构却暗示承诺结果。

❌ 错误示例：
```
（正文为可复用的证据保存清单，即"收藏"目标）
结尾：关注我，我保证帮你打赢官司！
```

✅ 正确做法：
```
（正文为可复用的证据保存清单）
结尾：以上清单建议保存备用；具体案件仍需结合个案证据判断，如有需要
可联系专业律师核实。
```

## 8. 虚假数据

**问题**：编造或夸大统计数据、成功率、案件数量，或把单一变量的变化说成因果结论。

❌ 错误示例：
```
我们团队成功率高达98%，已帮助上千名当事人挽回损失，发布这条视频后
咨询量暴涨10倍！
```

✅ 正确做法：
```
`【待补充：成功率、案件数量等数据来源及统计口径】`。
发布后当周咨询数由 3 增至 5（环比增加约 67%），同期还投放了其他
渠道广告，无法单独归因于本条视频。
```

## 使用建议

- 发布前对照 `checklists/pre-publish.md` 和 `QUALITY-GATES.md` 自查。
- 遇到无法核实的信息，统一使用 `【待补充】` 或 `【需核实】` 标注，不要留白也不要编造。
- 如发现新的错误模式，欢迎提交 PR 补充案例。
