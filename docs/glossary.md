# 术语表

- **来源锁定**：记录输入来自何处、何时取得、能否公开以及每个关键事实的出处。
- **脱敏**：移除或泛化可直接或组合识别个人/组织的信息；不等于当然可发布。
- **事实**：由输入或可核验来源明确支持的事项。
- **主张**：当事人、对方或第三方的陈述，尚不当然等于已证实事实。
- **法律判断**：基于特定事实和规则形成的专业判断，必须说明条件和核验状态。
- **传播目标**：希望观众产生的主要行为，如收藏、讨论、转发、继续观看或关注。
- **内容类型**：组织内容的方法，如故事、教育、对比和实操。
- **Hook**：开头对目标受众作出的注意力和价值承诺。
- **CTA**：内容末尾建议观众采取的下一步行动。
- **有效咨询**：符合预先定义的服务范围和信息完整度的咨询，不等于正式委托。
- **完播率**：完整播放次数除以有效播放次数；具体口径以平台定义为准。
- **来源账本**：句子或主张与其来源、状态和公开权限的对应记录。
- **教学情景**：为演示结构而虚构的材料，必须显著标注，不得包装成真实办案经历。
- **人工终审**：由有权限且具备专业判断的人对发布内容作最终决定。
- **阻断项**：未解决前不得继续生成或发布的高风险问题。
