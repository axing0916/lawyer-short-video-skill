# 来源锁定规范

## 来源级别

| 级别 | 示例 | 可用于何处 |
|---|---|---|
| S1 | 用户提供且已脱敏的判决/合同/证据摘录 | 在授权范围内支持事实 |
| S2 | 权威机关现行公开文本 | 支持法律规则，仍需核验适用性 |
| S3 | 用户的当事人陈述或工作笔记 | 只能标为陈述或线索 |
| S4 | 新闻、自媒体、二手总结 | 支持选题线索，不直接支持法律结论 |
| S5 | 模型生成、记忆或无链接内容 | 不得作为事实和法律依据 |

## 最小记录

每个来源记录：`source_id`、类型、标题/说明、提供者、取得日期、公开权限、脱敏状态、效力/可信度状态和备注。

每个关键句关联至少一个 `source_id`。无法关联时标 `【待补充】`；法律效力或适用性不明时标 `【需核实】`。

## 冲突处理

不同来源冲突时不得自行选择“更像真的”版本。并列记录冲突、证据强弱和待确认事项，必要时停止生成结论型文案。
