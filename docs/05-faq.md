# 常见问题

## 这是法律意见系统吗？

不是。它整理材料和生成表达草稿，法律结论须由执业律师结合事实、证据、程序、现行规则和当地实践核验。

## 可以直接粘贴客户案卷吗？

不可以。请先由你自行完成脱敏，不要上传未脱敏原始案卷。

## 为什么不提供“真实成功案例库”？

仓库无法证明未经来源和授权记录的案例真实。内置内容只作为明确标注的虚构教学情景；真实案例必须由使用者提供并承担核验、授权和脱敏责任。

## 五套公式是否被删除？

没有。它们被修订为五种传播目标：收藏、讨论、转发、探索、专业信任。案源是更下游的业务结果，不能由单条公式保证。

## 为什么没有预设完播率和咨询率？

不同平台、账号、选题、投放、样本量和统计口径不可直接比较。预设数字会制造虚假精度，应以账号真实基线和实验数据为准。

## 可以自动写入 Obsidian 吗？

Codex 在获得明确目录权限后可写 Markdown 文件，但本项目默认只提供模板和路径规范，不宣称已配置云同步或双向同步。

## 需要 API Key 吗？

把本仓库作为 Codex 本地项目或 Skill 使用时，不以单独 API Key 为前提。自建 API 脚本属于另一种部署方式。

## 可以一键发到抖音吗？

不能。发布涉及账号授权、平台接口、审核和运营决策，不在本版本范围内。

## 生成后可以直接发布吗？

只能进入人工终审。存在 `【待补充】`、`【需核实】` 或高风险项时不得发布。

## 如何判断有效咨询？

建议定义为：目标服务范围内、存在具体法律需求、提供必要基础信息且同意后续沟通的咨询。定义应在统计周期内保持一致。
