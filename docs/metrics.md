# 数据与指标口径

## 基础漏斗

曝光 → 有效播放 → 关键节点留存 → 完播 → 互动 → 主页访问 → 私信/来电 → 有效咨询 → 预约 → 正式委托

每个环节分开记录，不能把“咨询成交/播放数”同时称为咨询率。

## 推荐定义

- 收藏率 = 收藏数 / 有效播放数
- 分享率 = 分享数 / 有效播放数
- 互动率 =（点赞 + 评论 + 收藏 + 分享）/ 有效播放数
- 有效咨询率 = 有效咨询数 / 有效播放数
- 咨询到委托转化率 = 正式委托数 / 有效咨询数

平台口径变化时，以平台当期定义为准并记录版本。

## 不可直接比较的变量

自然流量与投放、不同账号阶段、不同地域、不同服务领域、不同视频时长、不同统计窗口、异常热点和样本量。没有这些变量时，结论标 `【需核实】`。

## 实验原则

- 不预填“正常水平”或目标成功率；
- 先建立账号自身基线；
- 一次测试一个主要变量；
- 报告样本数和观察窗口；
- 相关性不等于案源因果关系；
- 未发生的数据保存为 `null`，不是 0。
