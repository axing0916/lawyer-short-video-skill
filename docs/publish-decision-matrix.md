# 发布决策矩阵

发布前必须先通过 [质量门槛](../QUALITY-GATES.md) 并完成律师人工终审。本矩阵不替代授权、脱敏或法律核验。

| 内容来源 | 低风险：可提交终审的条件与措施 | 中风险：补充核审措施 | 高风险：处理 |
|---|---|---|---|
| 真实案例 | 有发布授权、已去标识、关键事实可回溯、法律适用已核验；保留核验记录 | 组合信息可能识别、来源或地域待核验；泛化事实并标 `【需核实】` 后复核 | 无授权、可识别当事人、虚构或夸大结果；不得发布 |
| 虚构教学 | 明示“虚构教学情景”、不影射具体人、规则已核验；附适用边界 | 与真实材料过度相似或规则时点不明；重写情景、核验后再审 | 冒充真实案例、捏造裁判/律师经历；不得发布 |
| 观点评论 | 区分观点与事实、引用可核验公开来源、无效果保证；附来源和日期 | 争议事实或法律结论未核验；降为问题讨论并律师复核 | 诽谤、泄露隐私、煽动对立或将猜测说成事实；不得发布 |

## 发布后问题应急预案

1. 发现隐私、事实或法律错误：立即下架或停止传播，保全原稿、版本记录和来源；不要用未经核验的说明掩盖问题。
2. 收到当事人或平台投诉：记录时间、链接和诉求，转交负责人及律师核实；必要时暂停相关内容。
3. 更正发布：仅在事实、法律依据和权限完成复核后发布更正；明确更正的范围，不承诺任何结果。
4. 复盘：记录问题类别、触发的门槛和修复动作，更新材料或流程；缺失信息保持 `【待补充】` 或 `null`。
