# 高级使用

## 1. 先做变量隔离

测试内容时，一次尽量只改一个关键变量，例如 Hook、时长或 CTA。若同时改变选题、受众和账号发布时间，无法判断哪项造成差异。

## 2. 建立事实—主张账本

对高风险内容，为每句话记录：句子、类型、来源、置信状态、是否对外。类型只允许事实、当事人主张、法律判断、表达性意见和行动建议。

## 3. 双轨文稿

- 内部稿保留精确日期、金额、证据和法律检索结果。
- 发布稿仅保留必要且可公开的信息。

两稿使用同一内容 ID，避免脱敏后无法核对，也避免内部信息误发。

## 4. 多角度批量生成

批量前先生成角度矩阵。每个角度必须具有不同的受众问题或决策价值；仅替换 Hook 不算新角度。最多先生成 3 条，人工筛选后再扩展。

## 5. 长短版本

先完成 3 分钟证据充分版，再压缩为 90 秒和 60 秒。压缩优先删除背景装饰和重复论证，不删除适用条件、风险边界和关键行动步骤。

## 6. 地域与时间

法律结论至少记录：规则名称、条款/要旨、效力状态、适用日期、司法解释、地区性裁判或执业规则。无法确认时输出 `【需核实】`，不使用模型记忆补齐。

## 7. 指标解释

小样本波动大，单条爆款不能证明公式有效。至少保留曝光来源、发布时间、账号基线、样本量和异常事件。把内容与案源直接归因属于高风险因果跳跃。

## 8. 版本管理

每次修订保留内容 ID、脚本版本、改动变量、审核人和发布时间。不得事后覆盖原始版本，否则复盘会产生幸存者偏差。
