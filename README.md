# 律师短视频文案系统

一个面向中国律师短视频创作的 Codex Skill。它把已脱敏、来源明确的案例或法律材料，转为可追溯的选题、口播稿、字幕和复盘记录。

## 当前版本

- 版本：v1.0.0
- 发布日期：2026-09-01
- 状态：稳定。核心生成、审计模板和本地校验可用；平台发布、第三方工作台双向同步及效果基准尚未实现。

## 能做什么

- 把真实、已脱敏的材料拆成多个内容角度
- 生成 60 秒、90 秒或 3 分钟口播草稿
- 将传播目标与内容类型分开选择，避免公式互相冲突
- 标注事实来源、缺失信息和待核验法律结论
- 生成适合 Obsidian 保存的 Markdown
- 用实际发布数据进行周度或月度复盘

## 不能替你做什么

- 不能补造案例细节、裁判结果、法条或业绩数据
- 不能替代律师对现行法律、当地规则和执业规范的终审
- 不能仅凭 Markdown 自动连接 Obsidian、GitHub 或第三方平台
- 不能保证播放量、完播率、咨询率或案源转化

## 5 分钟开始

打开 [快速开始](docs/01-quick-start.md)，按输入卡填写一份已脱敏材料，再运行主提示词。安装到 Codex 时，以本仓库的 `SKILL.md` 为入口。

## 目录

- `docs/`：使用、集成、法律核验与数据口径
- `modules/`：输入、拆解、生成、数据和集成规则
- `libraries/`：Hook、CTA、词语和风险边界库
- `examples/`：全部为明确标注的虚构教学样例
- `templates/`：Obsidian、输入、审核和复盘模板
- `config/`：机器可读配置与 schema
- `tools/`：本地校验工具
- `tests/`：结构和内容安全测试

## 重要提醒

在粘贴客户或案卷材料前，请先由你自行完成脱敏。不要上传未脱敏的原始案卷。本项目中的教学情景不是法律意见，也不是可宣称为真实的办案结果；所有示例均明确标注为虚构。

发布前务必按 [发布检查](checklists/pre-publish.md) 逐项核验。
