# 输入校验规则

## 阻断

- `deidentified != true`
- 来源为空或关键事实无来源
- 权限为禁止公开
- 用户要求补造真实案情、裁判结果或律师履历
- 内容含未处理的凭据或个人标识符
- 运行敏感信息检测工具（`tools/detect-pii.py`）返回 `status == "blocked"`（命中身份证、手机号、信用代码或银行卡等高风险标识符）

## 警告

- 地区、法律时点或案件阶段缺失
- 仅有单方陈述
- 精确数据无法核对
- 规则可能已更新
- 同一事件存在冲突版本

## 通过

通过只表示可以进入拆解，不表示可以发布。输出必须保留所有警告。
