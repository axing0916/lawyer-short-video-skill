# 脱敏检查

## 阻断性直接标识符

姓名、身份证号、电话、邮箱、详细地址、案号、车牌、账户、统一社会信用代码、可识别头像/声音、精确工作单位。

## 组合识别风险

地区 + 行业 + 精确金额 + 日期 + 亲属关系 + 罕见事件，即使没有姓名也可能识别当事人。逐项判断是否为法律分析所必需。

## 处理顺序

1. 用户先自行脱敏；
2. 系统运行自动化敏感信息检测（`tools/detect-pii.py`），对身份证、手机号、统一社会信用代码、银行卡号及案号进行模式筛查；
3. 发现高风险标识符时阻断流程，中风险标识符（如案号）输出风险提示并要求人工复核；系统不代替用户保存“脱敏后的副本”；
4. 记录泛化前后是否影响时效、管辖、主体资格或金额计算；
5. 如无法同时保证准确和不可识别，放弃公开案例叙事。

脱敏检查通过不等于已取得发布授权。
