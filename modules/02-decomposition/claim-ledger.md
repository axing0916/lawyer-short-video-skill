# 主张账本

| 字段 | 说明 |
|---|---|
| claim_id | `CLM-001` |
| text | 原始或规范化陈述 |
| kind | fact/party_claim/legal_claim/opinion/action |
| source_ids | 支持来源 |
| status | verified/unverified/conflicted/missing |
| public_use | allowed/paraphrase_only/blocked |
| note | 核验和改写说明 |

成稿中的关键句应能映射回账本。无法映射的句子若含事实或法律主张，必须删除或标记。
